Aplicativo Android nativo (.apk) que sobe um container Ubuntu ARM64 transparente em segundo plano e abre diretamente a janela do Antigravity em tela cheia — sem precisar mexer em área de trabalho do Linux.

📱 Escaneie no Celular / Tablet

Aponte a câmera para baixar o APK direto no aparelho:

Link direto: Antigravity-Mobile-Linux.apk

⚡ Configuração Única do Motor Linux (1º Uso)

O APK usa o motor do Termux (F-Droid) em segundo plano para rodar o Ubuntu ARM64 com glibc >= 2.28 sem precisar de root. Na primeira vez, rode o comando abaixo no Termux (ou clique no botão de configuração dentro do próprio APK):

pkg update -y && pkg install -y git curl && git clone https://github.com/rafanunesran/antigravity-mobile.git && cd antigravity-mobile && bash install.sh
1

Baixe e Instale o APK

Clique no botão verde acima no seu tablet ou celular Android para baixar e instalar o app Antigravity.

2

Modo Kiosk (Single-App)

No tablet, o container Linux usa Openbox sem bordas para exibir exclusivamente a janela do Antigravity ocupando 100% da tela.

3

Auto-Boot em 1 Toque

Sempre que tocar no ícone do Antigravity no Android, ele acorda o motor Ubuntu ARM64 automaticamente e abre direto no app.
